Overflow occurs when the true answer is greater than 255 and needs a ninth bit in an 8-bit unsigned system. The extra bit cannot fit in the register. Do not confuse a carry between columns with overflow.

Exam answer pattern: State the numerical range → calculate the actual sum → explain whether it fits into 8 bits.
